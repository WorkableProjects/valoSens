## Deviations from the spec
- `summary` has extra fields beyond the spec: `misses`, `firstErrCm` (signed along-axis error of the first submovement), `firstSdCm` (its true SD), and for track `onTargetFraction`. The noise-scaling test needs `firstErrCm`.
- Stationary (zero-delta) samples are emitted at 1000 Hz during reaction/waiting/click delay so only lifts show up as gaps (a real recorder that only logs on movement would have to fill these, otherwise tSub*0.4 waits look like lifts).
- Timeout (no hit): `done = 4`, a final `{t, hit:false}` click is added at the end of the trial.
- Track task has no pad/lift model (lifts always 0); track `hit` = onTargetFraction > 0; 2D (yaw+pitch) on-target test.
- Track control: a delayed (0.15 s) predictive reference plus a proportional correction (Kp = 8/s) on top of velocity following; spec did not fix this, chosen so on-target fraction is meaningful (about 0.18 at cm=30, sigma0=0.02). Position noise is an Ornstein-Uhlenbeck process with SD = sigma0*1.25 and tau = 50 ms.
- Hit test for static trials uses 2D radial error (yaw and pitch) against wCm.
