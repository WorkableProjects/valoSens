**Agent:** executor-sonnet

## Goal
In real play, a crosshair is seen while the view sweeps across the scene (flicks, strafes). A static picture overstates how visible thin, low-contrast lines are. Add **motion rounds** to the crosshair visibility test: the scene behind the 4 options pans horizontally while the player chooses. The choice model learns whether the player's preference changes under motion.

## Decisions already made
- `X.xSession` gains `opts.motionRounds` (default 3 of the 8 rounds; the existing balance logic decides which ids; motion rounds are the rounds with index 2, 5 and 7) and marks them `motion: true`. Every round object carries `motion: boolean`.
- **UI:** in a motion round, each option's canvas animates.
  - The background is painted twice the canvas width once (offscreen), then blitted with a horizontal offset that moves at 240 px/s and reverses every 1.2 s.
  - The crosshair is drawn fixed at the centre each frame.
  - Under `prefers-reduced-motion`, motion rounds are shown static, but `motion: true` is still recorded with `reduced: true` added. The fit ignores the motion covariate for such rounds.
  - Animate with `requestAnimationFrame`, and stop all loops when the round changes or the screen unmounts. Check that no rAF loops leak: count active loops in a debug variable `window.__xhMotionLoops`.
  - The round header shows a small "Moving" tag in motion rounds.
- **Choice model:** add the covariate `"thin×motion"` (thin lines × motion indicator) and `"outline×motion"` (outline × motion) to the feature list. Ridge-regularise them like the others. Expose the fitted effects as `fit.motion = { thin, outline }` (or null if no motion rounds).
  - **Decision use:** if `fit.motion.thin < −0.5` (thin lines lose under motion), the recommendation steps line thickness up by 1 (within the existing head-size cap), with a reason line.
  - If `fit.motion.outline > 0.5`, it turns the outline on. Find where `recommend`'s crosshair geometry is decided (around line 530–565) and add these two rules there, with `why` text.
- **Results files:** `cleanRounds` keeps `motion` (boolean) and `reduced` (boolean). Old rounds without them default to `motion: false`.
