## Format 2 (decisions already made)
- `FORMAT = 2`. A session gains an optional `aim` object:
```js
aim = {
  version: "1.0.0",                 // aim.js VERSION
  dpi: { countsPerCm, effDpi, ratio, cv, consistent, accelSuspect } | null,
  pad: { value, sd, n } | null,
  reach: { value, sd, n } | null,
  trials: [ trial record ... ],     // CONTRACTS "Trial record" fields only; max 600 per session
  personal: { sigma0, tSub, vPeak, reachCm, tLift, padCm, countsPerCm: {value, sd, n}, accel: {suspect, ratio} } | null,
  rawInput: boolean,                // true if unadjustedMovement pointer lock was granted
  frameMs: number | null
}
```
- Top level also records `engine: "6"` when given (`build({ ..., engine })`).
- Sanitising, matching the existing style: numbers must be finite and inside sane ranges:
  - `cm` 2–300; `time` 0–30; counts 0–100.
  - `task` must be one of micro/flick/turn/track; `session` and `id` strings of 40 chars or fewer.
  - Booleans must be strictly boolean.
  - Personal entries must be `{value>0, sd>=0, n>=0}`.
  Invalid fields are dropped and the key is added to `_dropped`; invalid trials are dropped whole.
- **Answers:** add `ENUM` keys for the v6 questionnaire:
  - `rank` (same values as `stRank`)
  - `aimSkip` boolean (handled like `xSkip`)
  - Keep `glasses` in `ENUM`: old files still carry it, and it's harmless.
- **Migration:** format-1 files import unchanged, with `aim: null` on every session. A file with `format > 2` is rejected with the existing message.
- **Pooling:** extend `pooled(sessions, cur)` to also return `aimTrials`, the concatenation of every session's `aim.trials`. Tag each trial's `session` as `"f" + i` (the file's session index), or `"cur"` for the current run, so session intercepts work across runs. Return `personalLatest` as the latest non-null `personal`.
- `build(o)` accepts `o.aim` and `o.engine`. `MAX_BYTES` rises to 6 MB.
