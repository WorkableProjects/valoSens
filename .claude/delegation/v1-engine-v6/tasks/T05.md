## Goal
Engine v6 combines a population prior with a physical model. It needs two datasets. **No row may be invented**: every value must come from a page you actually fetched (or a search-result snippet that shows it), with its URL recorded.

1. **Population (D1):** Valorant sensitivity of as many players as possible, beyond pros. It sets the prior distribution of sensitivity (cm/360), by group.
2. **Physics calibration (D2):** players with sensitivity **and their mousepad model** (so usable pad width can be looked up), plus mouse weight and arm/wrist style where stated. It is used to estimate how much the physical model (pad size, aiming style) actually predicts sensitivity.

## Sources to try (order of value)

- Mousepad dimensions: manufacturer product pages (e.g. Artisan Hien/Zero XL = 49×42 cm, Logitech G640 = 46×40, SteelSeries QcK Heavy XXL = 90×40). Record the width (left-right) in cm and the URL.

## Output formats (decisions already made)
`population_v6.json`:
```json
{ "generated": "YYYY-MM-DD", "method": "...",
  "rows": [ { "name": "...", "group": "pro|semi-pro|streamer|high-elo|general", "rank": "radiant|immortal|...|null",
              "region": "na|eu|...|null", "dpi": 800, "sens": 0.35, "cm360": 46.65, "source_url": "...", "accessed": "YYYY-MM-DD" } ],
  "binned": [ { "source_url": "...", "group": "...", "rank": "...", "bins": [ { "edpi_lo": 200, "edpi_hi": 250, "count": 31 } ], "n": 0, "accessed": "..." } ] }
```
`cm360 = 914.4 / (dpi * sens * 0.07)` (= 360 / (0.07 · sens · dpi/2.54)); round to 2 decimals.

`physics_calibration_v6.json`:
```json
{ "generated": "...", "pads": { "<pad model>": { "width_cm": 49, "height_cm": 42, "source_url": "..." } },
  "rows": [ { "name": "...", "dpi": 800, "sens": 0.3, "cm360": 54.4, "pad_model": "...", "pad_width_cm": 49,
              "mouse_model": "...", "mouse_g": 58, "aim_style": "wrist|wrist+arm|arm|null", "aim_style_source": "url or null",
              "settings_url": "...", "accessed": "..." } ] }
```

`.md` files contain the method, sources with access dates, exclusions, and summary statistics:
- population: n, median, IQR, and the log-normal fit of cm360 (mean and SD of ln cm360) per group.
- physics: n with pad width, Spearman correlation of ln cm360 with ln pad width, median cm360 by pad-width tercile, and by aim_style when n ≥ 5 per group.

Include an honest "limitations" section.
