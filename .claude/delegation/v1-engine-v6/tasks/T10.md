# T10: CI workflow and engine snapshot grid

**Agent:** executor-haiku
**Depends on:** none
**Wave:** 2

## Goal
1. A GitHub Actions workflow that runs every test on push and pull request.
2. A snapshot tool that records the engine's output for 60 fixed player profiles, so every engine change can show a before/after table.

## Owns
- `.github/workflows/ci.yml` (create)
- `test/snapshot.js` (create)
- `test/snapshots/` (create the directory, plus `.gitkeep` only; the planner generates the stored snapshot)

## Read-only context
- `test/model.test.js` (style), `model.js` `recommend()` return value: `cm`, `lo`, `hi`, `confidence.label`, `posterior.ci80`, `cModel`

## Spec

### ci.yml
```yaml
name: CI
on: [push, pull_request]
jobs:
  unit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: node test/model.test.js
      - run: node test/xhair.test.js
      - run: node test/session.test.js
      - run: node test/aim.test.js
      - run: node test/sim.test.js
      - run: node test/snapshot.js --check
  e2e:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: npm install --no-save playwright@1.48.2 && npx playwright install --with-deps chromium
      - run: node test/ui.e2e.js
```
Use exactly these steps. (`test/aimtest.e2e.js` is added to the e2e job later by the planner.)

### test/snapshot.js
- **Profiles:** the cartesian product of
  - `pad` [25, 45, 90]
  - `limb` ["wrist", "forearm"]
  - `role` ["d", "c"]
  - `weapon` ["rifle", "sniper"]
  - `experience` ["new", "comp"]
  That's 48 profiles. Add 12 more:
  - `agents` ["Jett"], ["Omen"], ["Sova"], ["Chamber"], each with pad 45 and limb "wf" (4)
  - `current.cm` at 25, 50 and 90 with pad 45 (3)
  - `region` "na", "kr" (2)
  - `age` "35p" (1)
  - `mouseG` 95 (1)
  - `grip` "fingertip" (1)
  Every profile also has `dpi: 800`.
- **Recorded per profile:** `{ id, input, cm, lo, hi, ci80: [a,b] or null, cModel, label }`, numbers rounded to 4 significant digits. `id` is a stable string built from the input, e.g. `pad45-wrist-d-rifle-new`.
- **Modes:**
  - `node test/snapshot.js --update` writes `test/snapshots/engine.json` (pretty-printed, profiles sorted by id).
  - `node test/snapshot.js` (no flag) prints a diff table:
    - columns: id, old cm, new cm, % change;
    - only rows with |change| > 0.5%;
    - then a summary: n changed, median |change|, max |change|.
    - Exits 0.
  - `node test/snapshot.js --check` exits 1 if any profile's cm changed by more than 0.5%, or if a profile is missing. If the snapshot file doesn't exist, it prints "no snapshot yet" and exits 0.
- Plain Node, no dependencies. Runtime is fine to be slow (each recommend takes ~0.3 s).

## Acceptance criteria
- `node test/snapshot.js --check` exits 0 (no snapshot file yet).
- `node test/snapshot.js --update && node test/snapshot.js --check` exits 0. **Then delete `test/snapshots/engine.json`** (the planner generates it after engine changes land), but keep `test/snapshots/.gitkeep`.
- `python3 -c "import yaml,sys;yaml.safe_load(open('.github/workflows/ci.yml'))"` succeeds, or, if PyYAML is missing, `node -e` with a basic check that the file contains `jobs:`, `unit:` and `e2e:`.
- Only owned files changed.
