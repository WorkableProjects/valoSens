- **Full calibration** (~15 min): everything.
- **Continue from a results file**: the existing import card.

Each card has its title, time, and a one-line description. Make sure the existing import UI is still reachable (move `importCard()` onto this screen).

### 4. Questions

### 5. Aim-test part (part 2): one screen, id `aim`
- **Shown when:** not `S.aimSkip`.
- **Content:** a short explanation (what it measures, ~6 min, needs a mouse; "Thorough" toggle for 12 min) and a **Start aim test** button. A secondary **Skip** goes through the existing skip mechanism.
- **On start:** call `AimTest.start(host, opts, onDone, onCancel)` with:
  - `dpi: getDpi()`
  - `centreCm: M.recommend(Object.assign(buildInput(), { calibration: null })).posterior.median`
  - `density: function (cm) { posterior density by nearest grid point }` (from `R.posterior.grid/weights` of that recommend call)
  - `seed: newSeed()`
  - `session: "cur"`
  - `thorough: S.aimThorough`
  - `source: window.__aimSource || null` (test hook; see e2e)
- **onDone(res):** set `S.aim = res` and move to the next question. **onCancel:** return to the aim screen.
- After a completed test, the screen shows a summary ("42 targets, effective DPI 812") and a **Redo** button.
- `valid()` is true when the test is done or skipped.

### 6. buildInput()
Remove `glasses`. Add:
- `rank`
- `calibration: { trials }`, where trials = `V.pooled(S.prior, { aim: S.aim && aimForFile() }).aimTrials` when that is non-empty, else omitted
- `personal`: `S.aim.personal` if present, else `pooled(...).personalLatest`, else omitted

Keep everything else.

**Important:** if `M.recommend` throws for too few calibration trials, catch it in `buildInput`'s caller. Simplest: add `safeRecommend(input)` in core.js that retries without `calibration`, and attaches `note: "aimTooFew"`. Use `safeRecommend` where `M.recommend(buildInput())` is called today. It's called in results.js, which isn't owned, so define `safeRecommend` and **report the exact line in results.js that should call it**. T12 will switch it. Until then, prevent the throw in practice by only passing calibration when there are at least 3 tested levels with at least 8 non-warmup trials each.

### 7. Results file
- `downloadResults` passes `aim: aimForFile()` and `engine: M.ENGINE` to `V.build`.
- `aimForFile()` maps `S.aim` to the session.js format-2 `aim` object: `version`, `dpi`, `pad`, `reach`, `trials`, `personal`, `rawInput`, `frameMs`. It doesn't include trajectories (too large).
- Import fills `S.rank` and `S.aimSkip` from answers.
