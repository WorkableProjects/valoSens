# T03: Split index.html into CSS and JS files (pure refactor, no behaviour change)

**Agent:** executor-sonnet
**Depends on:** none
**Wave:** 1

## Goal
`index.html` is 167 KB: one `<style>` block (lines 10–432) and one inline `<script>` (lines 447–2018). Split it into separate files loaded with plain tags. It must stay a no-build app that works by opening `index.html` from disk (`file://`). Later UI tasks will each own one of these files, so they can run in parallel.

## Owns
- `index.html` (modify)
- `ui/**` (create)

## Read-only context
- `index.html` (the whole file)
- `test/ui.e2e.js` (browser test that must keep passing: it calls page globals like `S`, `X`, `renderQ` through `page.evaluate`)

## Target layout (decisions already made)
Move code **verbatim** (cut/paste; no rewrites, no renames, no reformatting) into these files, in this load order:
| File | Contents (current index.html line ranges, approx.) |
|---|---|
| `ui/styles.css` | everything inside `<style>` (10–432) |
| `ui/core.js` | 448–592: `"use strict"`, globals `M/X/V`, stale-cache check, state (`freshState`, `S`, `currentId`), helpers, `buildInput`, `el`, `choices`, `numField`, stats parsing, toggles, `xhInput` |

| `ui/main.js` | the final `renderQ();` call only |

Check the exact boundaries yourself; the ranges above are from a quick scan. Every file starts with `"use strict";`. All of them are classic scripts (no modules), so top-level `var` and `function` declarations stay global exactly as now.

- In `index.html`, replace the style block with `<link rel="stylesheet" href="ui/styles.css?v=6.0.0-dev">`. Replace the inline script with `<script src="ui/<file>.js?v=6.0.0-dev"></script>` tags in the order above, after the existing `model.js`/`xhair.js`/`session.js` tags. Change those three tags' `?v=5.0.0` to `?v=6.0.0-dev` too.
- Function declarations used before their file loads are fine only if they're called after `ui/main.js` runs. Check that no top-level statement in an earlier file calls a function defined in a later file at load time. If one does (for example `S = freshState()` calling `newSeed` from draw.js), move the smallest thing needed so the load order works, and list it in your report under "Deviations".
- Keep the `<html>`/`<head>` content (fonts, meta) and the body markup as they are.
- Add `ui/README.md` (short): one line per file describing what it owns, and the rule "classic scripts sharing global scope; load order matters".
